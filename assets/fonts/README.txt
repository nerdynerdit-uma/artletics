Orbitron
--------
orbitron-latin-variable.woff2 — latin subset, variable weight 400-900.

Used for the site menu only (see --display-font in assets/css/base.css). The rest of
the site keeps the original's "Helvetica Neue", Arial stack.

Designer: Matt McInerney
Licence: SIL Open Font License 1.1 — https://openfontlicense.org
Source:  https://fonts.google.com/specimen/Orbitron

Served from this repo rather than from Google's CDN, so the site makes no third-party
requests. If the file is ever replaced, give the new one a different name: Vercel
serves everything under /assets/ with a one-year immutable cache header.
