FAIR PRACTICE Code

De Fair Practice Code benadrukt transparantie, gelijke behandeling en het welzijn van alle deelnemers. Bij Artletics zorgen we ervoor dat deze principes door het gehele project worden nageleefd.

GOVERNANCE Code CULTUUR

De Governance Code Cultuur waarborgt goed bestuur binnen het project en de betrokken organisaties. Artletics volgt deze code om de kwaliteit van de uitvoering te optimaliseren.

Code DIVERSITEIT & INCLUSIE

De Code Diversiteit en Inclusie benadrukt het belang van inclusiviteit en het vieren van diversiteit binnen de culturele sector. Artletics past deze principes toe in de opzet en uitvoering.

Integratie in het Project

Door de toepassing van de drie codes in Artletics creëren we een solide basis voor goed bestuur, inclusie en eerlijkheid. Dit zorgt voor een positieve ervaring voor jongeren, waarin ze niet alleen meer leren over cultuur, maar ook sociale vaardigheden ontwikkelen en zich actief kunnen uiten.
